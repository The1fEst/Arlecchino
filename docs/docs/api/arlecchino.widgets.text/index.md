# Arlecchino.Widgets.Text

## Classes

| Type | Summary |
|---|---|
| [`EntryRow`](EntryRow.md) | A line being typed into, drawn on one row of the screen: a filter, a search, a field an application draws for itself. Text longer than the room it is given scrolls, so the caret is always on the screen. |
| [`EntryRuns`](EntryRuns.md) | A line being typed into, cut into the runs it is drawn as: what is plain, what is selected, and the symbol the caret stands on. The caret is written the other way round rather than wedged beside it. |
