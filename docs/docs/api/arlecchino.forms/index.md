# Arlecchino.Forms

## Classes

| Type | Summary |
|---|---|
| [`Field`](Field.md) | One row of a form: a label, the value beside it, and what happens when it is confirmed. Everything is read through delegates, so a field shows what the state holds now and follows the language it runs in. |
| [`Form`](Form.md) | A column of fields with their values lined up, and a help line under the selected one. It holds no values of its own, and the atom behind each field decides whether an edit can be undone. |
